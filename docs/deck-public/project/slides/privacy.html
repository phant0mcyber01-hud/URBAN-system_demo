Приватность

Камеры считают метры очереди, а не людей.

Лица, номера машин и маршруты никуда не уходят и не хранятся. С камеры уходят только числа.

Где камеры перекрёстка разбирает районный сервер, видео теперь идёт к нему только по закрытому каналу: по дороге его не подсмотреть.

07 / 13

Главный принцип проекта: защищать город, а не следить за жителями. Камера нужна только для того, чтобы измерить длину очереди в метрах. Видео обрабатывается рядом, в районе, и дальше не уходит. В центр приходят только числа: сколько метров стоит очередь на каждом подъезде. Новое: там, где видео перекрёстка разбирает районный сервер, оно идёт к нему только по закрытому каналу между шкафом светофора и районом. Кто подключится к проводу по дороге, видео не увидит. Если канал оборвался, видео просто не идёт: открытой обходной дороги у него нет, а светофор от этого не зависит. Проверяем это пока на компьютере; на настоящем оборудовании проверим на стенде.
