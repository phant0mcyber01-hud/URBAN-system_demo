Почему это безопасно

Только готовые планы

Можно лишь выбрать план, который инженер признал безопасным.

Всё временно

Команда сама истекает через 3 минуты. Откат живёт в самом светофоре.

Каждая команда подписана

Блок на перекрёстке проверяет подпись и отвергает подделки.

Сбой — как обычно

Пропала связь или вскрыли шкаф — светофор вернётся к своей программе.

Даже взломав сервер, аварию не устроить: светофор выполняет только безопасные планы.

08 / 13

Больше всего мы боимся взлома, поэтому система устроена так, чтобы даже полный взлом сервера не мог навредить на улице. Платформа не задаёт секунды и не включает лампы: она может только выбрать один из планов, которые инженер признал безопасным для этого перекрёстка. Затор устроить можно, аварию нельзя. Любая команда сама истекает через три минуты, и откат хранится в самом блоке на перекрёстке, а не на сервере. Блок проверяет подпись каждой команды и отказывает подделкам и повторам. Операторы входят по паролю и коду с телефона, каждое действие записывается в журнал, который нельзя незаметно переписать.
