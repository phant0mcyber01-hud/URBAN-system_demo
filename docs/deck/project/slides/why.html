Идея владельца: тяжёлую работу, то есть распознавание камер, делает районный сервер. Видео идёт по короткой районной сети, в офис уходят только числа. Новый район — новый шкаф. Правило про кадры мы ослабили: раньше они не покидали шкаф, теперь не покидают район.
