Цель: если взломали, получить как можно меньше. Таблица честная, красным — два тяжёлых случая. Root на работающем блоке может прочитать файл ключа этого блока и выдавать себя за него, пока его не отзовут в «Устройствах»; командовать он не может: подписывает только центр. Закроется это подписью внутри чипа TPM. Взломанный центр может только выбирать планы, которые инженер утвердил в паспорте перекрёстка, и только на три минуты аренды. Взломанный район видит шифртекст и может врать о своих очередях, но не командовать. SSH: только ключи, современная криптография, снаружи по TCP слушает только SSH. Украденный диск без TPM не зашифрован, и экран машины об этом пишет.
