Двенадцатый шаг сделал раздачу обновлений из центра пригодной для парка из двух платформ и безопасной для города. Первое — выпуски по платформам. Команда release add сама читает из подписанного пакета, для какой он системы: urban-edge-x86_64 или urban-edge-aarch64; пакет для любой другой системы центр не принимает, а указать платформу руками нельзя, значит, и ошибиться ею тоже. У каждой платформы свои номера: выпуск 2 для x86 и выпуск 2 для ARM лежат рядом. Каждый блок и районный сервер сообщает свою платформу в отчёте о здоровье — из файла /etc/rauc/system.conf, — и центр предлагает ему только пакет его платформы. Устройство, которое платформу не сообщает, то есть система до двенадцатого шага, считается x86, как раньше. Второе — волны. Первая волна — названные устройства, ключ --devices, или доля парка, ключ --wave: у каждого устройства постоянный ранг от 0 до 99 из хэша его имени, поэтому первыми всегда идут одни и те же устройства. Дальше администратор расширяет волну командой promote — до большей доли или всем. Третье — сама остановка. Если устройство волны сообщило, что помощник отказал пакету или скачан не тот пакет, или если оно поставило выпуск и откатилось на старую систему, центр останавливает выпуск сам: больше никому его не предлагает и не отдаёт, пишет в журнал rollout-halted с устройством и причиной, а во вкладке «Устройства» видно «раздача остановлена» и почему. Устройства, которые уже работают на этом выпуске, остаются как есть. Остановка действует на номер целиком: x86 и ARM одного номера собраны из одного кода, поэтому откат x86-блока останавливает и пакет ARM. Продолжить — resume, снять навсегда — withdraw: решает администратор. Проверка в QEMU — check-rollout.mjs: центр, блок x86 и блок ARM; каждый получает только свой пакет, сломанный выпуск 3 в первой волне из x86-блока откатывается, раздача останавливается, блок ARM свой выпуск 3 не получает даже после расширения волны, а после resume получает сразу — это контроль. Что открыто: проверено только в QEMU, центр верит тому, что сообщают устройства, а сам центр по-прежнему обновляется вручную.
