Пять вещей, которых мы не делали на этом шаге, и мы не прячем их. WireGuard закроет сеть между перекрёстком и районным шкафом; сами соединения блока уже защищены сквозным TLS до центра. ARM нужен для дешёвых плат, пока лёгкий блок работает на том же образе x86-64. Подпись внутри TPM закроет тяжёлый случай из таблицы про взлом, root на работающем блоке; Secure Boot закроет подмену системы на диске. Раздача обновлений с платформы нужна, чтобы не ходить по SSH на каждый блок.
