Это экраны, которые видит монтажник, воткнув монитор в мини-ПК: ничего вводить не нужно. Слева блок: имя, ключ, код подключения, который администратор вставляет в центре управления. Справа пилотная машина: адрес интерфейса и план мощности. Демонстрация поднимается одной командой на ноутбуке разработчика, node os/demo.mjs: блок, районный сервер и центр, экраны в браузере. Без аппаратного ускорения загрузка идёт медленно, минуты.
