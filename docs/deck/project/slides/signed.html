Ключевая идея защиты. Блок подключается к адресу районного сервера, но проверяет сертификат центра. Районный сервер пересылает соединение ядром, ни одна программа на нём не держит байты. Поэтому его взлом не даёт ни прочитать отчёт блока, ни подделать команду: ключ подписи есть только у центра. Свои собственные отчёты об очередях взломанный районный сервер подделать может — центр принимает их только для его перекрёстков.
