# web — интерфейс центра управления

Карта района в 3D, панели вкладок, вход. Чистый JavaScript без фреймворка, сборка Vite, карта —
deck.gl и MapLibre. Сервер раздаёт уже собранную версию из `dist/`.

## Собрать после правок

```bash
cd web
npm install      # один раз
npm run build    # после любых правок в src/
```

Для разработки с горячей перезагрузкой: `npm run dev` (запросы к API идут на платформу на :8080).

## Что где

| Файл или папка | Что внутри |
|---|---|
| `index.html` | каркас страницы: верхняя полоса, окно входа, панели |
| `src/main.js` | точка входа: связывает карту, панели, вход и живые данные |
| `src/state.js` | состояние на стороне браузера: снимок с сервера плюс поток событий |
| `src/api.js` | запросы к серверу и сессия |
| `src/ui/panel.js` | вкладки: обзор, пробки, камеры, устройства, история, безопасность |
| `src/map/` | карта и навигация, окно камеры, поиск, карточка объекта |
| `src/scene/` | 3D-сцена: здания, дороги, машины, подсветка проблем |
| `src/style.css` | оформление |
