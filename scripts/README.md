# scripts — запуск на Windows

| Скрипт | Когда |
|---|---|
| `setup.ps1` | один раз: окружение `.venv`, зависимости, сборка интерфейса, данные района (нужен интернет) |
| `run.ps1` | каждый раз: платформа на http://localhost:8080 вместе с демо-блоками |

Из корня проекта: `scripts\setup.ps1`, затем `scripts\run.ps1`. В VS Code то же самое — в
«Terminal → Run Task…» (пункты 1 и 2).
