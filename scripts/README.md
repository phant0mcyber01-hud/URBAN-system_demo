# scripts — запуск на Windows

| Скрипт | Когда |
|---|---|
| `setup.ps1` | один раз: окружение `.venv`, зависимости, сборка интерфейса, город и демо-двойник из OpenStreetMap (нужен интернет) |
| `run.ps1` | настоящая система на http://localhost:8080: город из `data/city`, реальные блоки URBAN Edge |
| `demo.ps1` | демо-двойник для показа: трафик SUMO, синтетические перекрёстки, эмулированные блоки |

Из корня проекта: `scripts\setup.ps1`, затем `scripts\run.ps1`. В VS Code то же самое — в
«Terminal → Run Task…» (пункты 1 и 2).
